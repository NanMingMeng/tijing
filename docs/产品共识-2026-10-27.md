# 题镜 · 第一版产品共识

日期：2026-10-27

## 定位

- 名称：题镜
- 用户：学生为主，老师也可使用同一个 APP
- 不做账号、登录、班级管理
- 第一版安卓优先，Flutter 开发，保留以后出 iOS
- 最低 Android 10.0
- APK 直接分发，不上应用商店
- GitHub 开源，MIT 许可证

## 首页

- 大按钮“拍照搜题”
- 同时露出题库入口和历史入口
- 浅色、简洁、专业风格

## 题库

- 导入 Excel、Word `.docx`
- 老 `.doc` 提示用户另存为 `.docx`
- Excel 支持列名手动映射
- Word 排版不固定时：本地规则优先，失败后用户可选择调用自己的大模型补拆
- 有问题的题目逐条标红，允许导入后修改
- 题型：单选、多选、判断、填空、简答
- 第一版不支持公式、表格、图片题、手写题
- 支持多个题库；可合并成一个，也可每个文件单独成库
- 导入时自动查重：几乎完全重复的自动跳过；只是相似的标“疑似重复”，绝不自动合并
- 字段：题目、题型、选项、答案、解析、题源、科目、章节、标签、难度
- 手机端可改题、删题、加题
- 可导出 Excel、Word
- 第一版保证 1 万题以内流畅；超过提示拆分

## 拍照搜题

- 拍照和相册选图
- 拍照后手动框选题目区域
- 第一版一次只处理一道题
- OCR：PaddleOCR 移动版，离线内置
- 中文、英文、数字、字母
- 拍完直接搜；低置信度或搜错时才让用户改识别文字
- 候选最多 3 道
- 最像的题明显领先才自动显示答案，否则只给候选

## 大模型

- 用户自己填写 API Key，APP 不内置密钥
- 预设：DeepSeek、通义千问、智谱、硅基流动、OpenAI、Claude、Gemini
- 同时支持自定义接口
- 第一次点击 AI 作答时提示用户题目会发送给模型服务
- 任何题目都可主动点“AI 作答”
- 只有用户点击后才调用
- 返回答案、解析、解题步骤
- 允许模型说“无法确定”
- 题库答案与 AI 答案必须分开显示
- AI 结果保存在本地历史
- 历史支持单条删除、一键清空

## 分享与备份

- 不做链接、二维码分享
- 分享 APP 专用题库文件，对方直接导入
- 支持整库分享和选题目分享
- 分享文件包含被分享题目及其 AI 记录
- 分享文件不包含其他历史、设置、API Key
- 一键备份/恢复，并提醒定期导出
- 备份包含题库、AI 历史、设置
- 备份不包含 API Key
- 题库和历史不加密

## 更新

- APP 内检查新版本
- 版本信息和 APK 放 GitHub Releases

## 验收

- 用《建筑专业知识练习题库.xlsx》作为第一份真实题库
- 1007 题：单选 728、多选 279
- 20 张清晰打印题照片，前 3 候选至少命中 16 张
- 普通中端安卓机，3～5 秒出候选
